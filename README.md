# Sunday 22 November 2026: 36 stories, 7 regions

A cream newspaper front page summing up Sunday 22 November 2026 in one image: a huge serif masthead, a numbers strip, a region bar, a UTC timeline, a dotted world map with numbered pins, and 15 drawn scenes across 3 leads and 12 grid stories, plus a list of the rest of the day. Every story carries a certainty badge (REPORTED / CLAIM / CONFIRMED), and a DATE CHECK box keeps earlier days' news out.

Leads: 186 drones over Ukraine (161 downed, Dymer block); COP31 ends with no deal in Antalya; Iran's radar claim vs Bahrain's denial. 36 verified stories across 7 regions, checked against AP, Reuters, BBC, AFP and Al Jazeera roundups of 22 November 2026.

## Run

```sh
node main.ts
```

`main.ts` (Node 22, standard library only, no network) copies `entry.png` to `/output/entry.png`. It runs twice and writes the same bytes both times.
